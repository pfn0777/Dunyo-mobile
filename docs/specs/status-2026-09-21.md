## 2. Nima qilingan (kod bor, testlar bilan)

- **Domen mantig'i**: narx hisobi (`calcTotals`), holat o'tishlari, nasiya (`installmentMonthly`), telefon, initData HMAC, import validatsiyasi. `shared/test` da qoplangan.
- **SQL**: `create_order` (variant_id tartibida qulf, idempotency, stock/price/region/min_order xatolari), `set_order_status` (bekor qilinganda stock qaytishi, ikki marta qaytmasligi). PGlite'da 23 test.
- **API**: public / customer / admin / webhook marshrutlari, kanal gate (fail-open), oxirgi-owner qo'rig'i (fail-closed), Telegram xabarlari (`orderNotify.ts`).
- **Mini App**: 5 ekran + checkout + buyurtmalar + manzillar, savat (localStorage + CloudStorage), admin panel (mahsulot, variant, import, bannerlar, viloyatlar, buyurtmalar, sozlamalar, adminlar, audit).
- **Infra fayllari**: `docker-compose.yml`, `Caddyfile`, `backup.sh`, `migrate.sh`, `set-webhook.ps1`, `docs/deploy.md`, CI workflow.

## 3. Nima qilinmagan yoki isbotlanmagan

**Kod darajasida bo'shliq: topilmadi.** Spec'dagi 25 acceptance bandining hech biri "bajarilmagan" emas. Lekin 18 tasi faqat jonli muhitda isbotlanadi:

1. **Hech qanday deploy bo'lmagan**: domen, bot tokeni, guruh chat ID, GPG kalit, rclone remote yo'q.
2. **Repo `origin`ga push qilinmagan** — CI (GitHub Actions) hech qachon ishlamagan.
3. **Haqiqiy Postgres'da sinalmagan**: parallel buyurtma (`FOR UPDATE` kutishi) PGlite'da faqat ketma-ket sinalgan.
4. **Telegram bilan real aloqa sinalmagan**: guruh xabari, joyida tahrirlash, `getChatMember`, tugmalar.
5. **UI brauzerda qo'lda ko'rilmagan** (bu sessiyada): Stitch dizayniga moslik, bottom sheet, checkout interaktivligi. Component testlar ataylab yo'q.
6. **Excel import** spec'dagi aniq stsenariy (50 qator / 3 xato → 47) end-to-end sinalmagan; faqat bo'laklar.
7. **Rasm yuklash** haqiqiy 4 MB JPG bilan (<150 KB) va Caddy `immutable` header sinalmagan.
8. **Backup va restore** birorta ham marta ishga tushirilmagan.
9. **Logo** — placeholder (386 bayt), haqiqiy brend belgisi emas.
10. **5 ochiq savol** javobsiz: domen, bot/guruh, viloyat narxlari, pickup manzili, kafolat matni.

## 5. Xulosa

Kod bazasi lokal muhitda **ishlaydi va toza**: typecheck, 344 test, build, secret scan, kompilyatsiya qilingan API boot va auth/webhook himoyasi tasdiqlandi. Production'da ishlashi haqida hozircha hech narsa deyish mumkin emas: deploy va real Telegram/Postgres sinovi yo'q.
